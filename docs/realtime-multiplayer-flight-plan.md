# 实时多人同图飞行：玩法探索文档

> 状态：**头脑风暴 / 方向探索**，非排期文档
> 一句话愿景：一张地图里多个人同时飞，你能看到别人的飞机在移动，从"各玩各的 PK"变成"约在一起飞"。

---

## 1. 现状与直觉

目前四种模式（自由 / PK / 选点 / 巡航）本质上都是**单机体验**：

- 自由、选点、巡航：全程只有自己；
- PK：虽然有"对手"，但那是**异步的同一张考卷**——服务器给双方同一个目标点，各自在自己地图上找，靠轮询 `version` 字段知道对方的步数/输赢。你看不到对方在哪、怎么飞、离目标多近，体感上和单人没有区别。

我们想要的新东西：

- 进入一个房间后，地图上除了自己，还有**别人的飞机在实时移动**；
- 每个人的屏幕仍是**自己的第一人称视角**（地图中心、缩放都由自己控制），但别人作为"世界中的动态小飞机"出现在你的地图上；
- 可以约朋友一起开一局，有竞速、有相遇、有表情互动，后期能聊天、尾随、丢道具。

这和现有 PK 的关系：**现有 PK 不用删**（好友不在线也能异步约战，有其价值），实时模式是"双方都在线时"的升级体验。

---

## 2. 核心设计问题拆解

想不通的几个问题，本质是"起点 × 目标点"怎么组合。先把矩阵摆出来：

| | **目标点相同** | **目标点不同** |
|---|---|---|
| **起点相同** | ① 同起跑线竞速 | ② 同基地分头出发 |
| **起点不同** | ③ 会师 / 追逐赛（≈现有PK的实时化） | ④ 各飞各的（无交集，不成立） |

**关键结论：交互必须有"交集"。** 交集有三种：

- **空间交集**：两人会飞到同一片区域（相遇、擦肩）；
- **目标交集**：两人抢同一个点、或同一条路线（竞速、占领）；
- **社交交集**：即使目标不同，人在同一间"屋子"里（自由飞行大厅，纯社交）。

第④种（不同起点+不同目标）没有任何交集，就是两个单人游戏拼在一起，**不成立**。所以玩法设计都要落在"制造交集"上。

### 逐个回答

**Q：两个人找的地点一样吗？**
竞速类：一样（同一目标/同一路线，比谁快）。协作类：不一样（分头找点，共享进度）。抢点类：大家抢同一批散点。

**Q：起点一样吗？**
- "同起跑线"（同起点）最有仪式感：3-2-1 倒计时，同时起飞，适合竞速；
- "不同起点"更真实、更像现实中约飞：每人从自己所在位置/随机城市起飞，约定一个会合点，适合会师赛；
- 现有 PK 已经是"不同起点+同目标"，实时化后天然成立。

**Q：怎么有交互性质？**
见第 3 节玩法。交集制造出来后，交互自然发生：相遇时发表情、竞速时看对方进度条、抢点时看谁手快。

## 3. 玩法模式发散（房间类型）

### 模式 A：竞速巡航赛 Rally（最推荐先做）
- 规则：同一起点起飞，同一串目标点（可复用专题 collection 的点位序列），巡航方式飞，先全部飞完者胜；
- 交集：目标完全相同，全程路线重合度高，**经常能在地图上看到对方飞机**；
- 信息差设计：能看到对方"飞到第几个点"的进度和大致方位，**但看不到对方目标点的具体位置提示**——提示文案各看各的，保留猜测乐趣；
- 观感：像两群飞机在同一条航线上竞速，"他已经到第二个点了！"的紧迫感。

### 模式 B：会师赛 Rendezvous
- 规则：两人从不同城市起飞，目标是同一个地点，看谁先飞到（或约定"相差 10 秒内同时到达"算双赢成就）；
- 交集：终点相同，前期天各一方、后期两架飞机越飞越近，**"两架飞机在地图上汇聚到一起"的瞬间是情绪高点**；
- 可做成单局快速赛（一个目标点，3-5 分钟）。

### 模式 C：协作寻路 Co-op
- 规则：一批目标点分给两个人（或各自领一半），分头飞，**全部点都被找到才算共同通关**；
- 交集：目标不同但进度共享——队友找到的点在你地图上点亮，你飞过时能看到队友的标记点；
- 适合情侣/好友轻松局，没有对抗压力。

### 模式 D：抢点占领 King of the Map
- 规则：地图上随机散布 N 个点，谁先飞到（视野判定命中）点就归谁，变成本方颜色，限时结束比谁占得多；
- 交集：所有点对所有人可见，**多人抢同一个点时"差一点被抢"的刺激感最强**；
- 衍生：点被占领后对方可"夺还"（飞到待几秒），打出拉锯战。

### 模式 E：自由飞行大厅 Free Flight（社交沙盒，建议作为"大厅"存在）
- 规则：无目标、无输赢，开放房间，进来就在全国地图上随便飞、随便逛；
- 能看到房间里所有人的飞机，可点击某人"跟随视角"（镜头尾随他飞）、发表情、发预设短语；
- 定位：**社交大厅 + 约战入口**——在这里看到熟人在线，点"约一局"直接拉进模式 A/B 的房间；
- 这是"飞机飞来飞去"氛围感最强的模式，也是后期所有社交功能的载体。

### 模式 F/G（远期脑洞）
- **接力赛 Relay**：一串点每人飞一段，到达交接点后下一人自动接管；
- **猫鼠 Tag**：一人当"鬼"，飞到别人视野范围内持续 3 秒算抓到，被抓者变鬼；
- **护航/干扰**：呼应点子池 IP-007，竞速中可给队友加油加速、给对手制造"气象干扰"（需谨慎，见第 7 节风险）。

> 建议组合拳：**自由飞行大厅（E）是"广场"，竞速（A）/会师（B）/抢点（D）是广场里随时能开的"一局"**。

## 4. "看到别人"怎么表现

- **别人的形态**：小飞机图标 + 昵称牌 + 朝向（按移动方向旋转）+ 速度档位的长短拖尾；自己仍保持第一人称，不改变现有巡航操作；
- **距离太远时**：屏幕边缘显示**雷达箭头**——"✈️ 队友在东北方向 · 约 1200km"，避免全国视角下一堆飞机挤在一起；
- **同屏相遇时**：擦肩音效、双方头顶可弹表情气泡（👍🎉😱✈️）；
- **zoom 差异问题**（关键细节）：你在 zoom=5 全国视角、队友在 zoom=12 城市视角——两人看到的比例尺完全不同。解法：别人的飞机按**世界坐标**渲染，在你当前 zoom 下该在哪就在哪；离你的视野中心太远就收进边缘雷达箭头，不强行显示；
- **别人的目标点/提示不显示**：你只能看到别人的飞机和他已完成的点，看不到他的题目提示，防止直接"抄答案"；
- 巡航时地图在平移，别人飞机的世界坐标持续更新，靠插值动画平滑移动（不能一顿一顿）。

## 5. 社交交互层次（从轻到重，逐步放开）

| 层级 | 内容 | 说明 |
|---|---|---|
| L1 存在感 | 看到飞机、在线列表、飞行轨迹 | P0 就有，"有人在"的感觉 |
| L2 快捷表达 | emoji 表情气泡、预设短语（"加油！""等等我""你飞太快了"） | 不做自由输入，免审核成本 |
| L3 轻互动 | 路过撒花点赞、"跟随 TA"视角按钮 | 氛围向 |
| L4 道具互动 | 给队友加油、给对手气象干扰 | 呼应点子池 IP-007，需防负面体验 |
| L5 文字/语音聊天 | 房间内聊天 | 需内容审核，放后期 |
| L6 关系链 | 好友列表、邀请码、约战通知、战绩 | 社交沉淀 |

原则：**先做"安全的表达"（表情/预设语），后做"自由的表达"（聊天）**；先做正反馈（加油、点赞），谨慎做负反馈（干扰道具）。

## 6. 技术方向（粗颗粒）

- **传输**：实时位置必须 **WebSocket**（FastAPI 原生支持）；现有 HTTP 轮询无法支撑"看到飞机在飞"的流畅度。降级方案：WS 连不上时退化为 2-3 秒轮询位置包；
- **同步什么 / 频率**：不需要逐帧同步。客户端每 **200-500ms** 发一次 `{位置, 朝向, 速度档, 当前状态}`，服务端广播给同房玩家；客户端用插值（interpolation）把别人的飞机平滑移动到新位置；
- **房间状态机**：`waiting（等人）→ countdown（3-2-1）→ flying → finished`，复用现有 4 位房间码体系；
- **判定权威**：命中目标、占领点位全部以**服务端计算**为准，客户端只负责上报视野，防作弊；
- **状态存放**：房间实时状态放进程内存 / Redis；对局结束后的战绩落库（复用 pk_games / player_sessions 结构）；
- **流量估算**：8 人房，每人 2Hz 上报、广播给 7 人，约 112 包/秒 × 每包几十字节，压力极小；
- **复用资产**：巡航模式的速度档位/zoom 降级/标注层隐藏逻辑、专题点位、积分 PC、勋章体系、房间码、微信用户体系全部可复用。

## 7. 风险与开放问题

1. **等人体验**：房间开了人不齐怎么办？——建议先做"2 人即开"，后期考虑机器人填充或允许"边自由飞边等"；
2. **小屏拥挤**：全国视角下多人飞机 + 雷达箭头在手机小屏上可能杂乱，需要实测密度，上限人数建议先锁 4-6 人；
3. **陌生人骚扰**：自由大厅/表情系统面向陌生人，预设短语也要筛选；自由聊天必须配审核（可先只允许好友间聊天）；
4. **公平性**：干扰类道具、网络延迟（有人卡顿时飞机瞬移）对竞速公平性的影响，竞速模式建议**先不做任何道具**，纯拼技术；
5. **"看到别人飞"会不会分散找地点的注意力**：别人的飞机视觉权重要低（半透明、小图标），主角永远是自己的视野和题目；
6. **成就沉淀**：实时对局是否发勋章/积分？建议竞速胜场计入新的"飞行执照"类成就，与现有专题勋章并行。

## 8. 建议的演进路线（仅供参考，非承诺）

- **P0 技术验证**：WebSocket 通道 + 2 人自由飞行，双方能在地图上看到对方飞机实时移动、朝向、拖尾。**先证明"同一片天空"的感觉成立**；
- **P1 竞速赛**：模式 A（同起点同路线巡航竞速）+ 房间状态机 + 在线列表 + emoji 表情气泡 + 结算面板；
- **P2 模式扩充**：会师赛 B（单目标快速局）+ 协作寻路 C；
- **P3 社交化**：自由飞行大厅 E + 跟随视角 + 好友/邀请 + 约战入口；
- **P4 玩法深化**：抢点占领 D、道具、接力/猫鼠等脑洞、观战模式、战绩与成就。

> 核心判断：**P0 的"两个人在地图上互相看到飞机飞"是整个方向的命门**——如果这个瞬间的体感成立（"哎你在那儿！我看到你了！"），后面所有模式都值得做；如果不成立，省下所有后续投入。建议先花最小代价做 P0 验证手感，再谈玩法。

## 9. 待拍板的问题（看完后可讨论）

1. 第一个验证原型，你想先看到哪种：**2 人自由飞互相看见**（纯技术手感），还是**直接做一局竞速赛**（完整玩法闭环）？
2. 实时模式是**好友约战为主**（私密房间+邀请码），还是要做**陌生人随机匹配/开放大厅**？
3. 别人的飞机在你屏幕上，视觉上你倾向：小飞机图标、还是带头像的小圆点？
4. 竞速赛用**专题路线**（固定点位序列）还是**随机点位**？
