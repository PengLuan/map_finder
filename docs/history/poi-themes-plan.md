# 猜地图 POI 主题素材库方案

> 状态：方案文档（不改代码）
> 范围：为 map 项目扩充 POI 目标点素材，规划 32 个主题、数据来源与落库方式
> 现状参考：`backend/app/models.py`（POI 表）、`backend/scripts/seed_data.py`（现有 ~80 个 POI）

---

## 1. 目标与原则

- 把"猜地点"从泛地标扩展到**结构化主题**，玩家可按主题选场（如"猜 985 院校"），提升复玩性与传播点。
- 所有素材来源**公开数据**（政府名录、UNESCO、维基百科、CTBUH 等），坐标可批量补齐。
- 复用现有 `POI` 表，仅新增 `category` 取值与数据行；不改动表结构。

### POI 字段映射约定
| 字段 | 取值约定 |
|---|---|
| `category` | 主题标识（如 `university_211`、`peak_famous`、`airport_major`） |
| `lng/lat` | WGS84 坐标（高德返回为 GCJ-02，入库前需转换，见 §5） |
| `adcode` | 行政区码（与 Region 表对齐，便于按省筛选） |
| `hint_text` | 一句话线索（不泄露地名，如"1902 年建校的工科强校"） |
| `difficulty` | 1~5，按地标辨识度估（故宫=2，普通 211=4） |
| `summary/cover_url` | 选填，结算页展示 |

## 2. 主题设计原则
1. **最低体量门槛**：每主题有效 POI **≥50 个**，凑不足的合并到相近主题或剔除（如单独的峡谷/瀑布/隧道/帝陵/核电站体量不足，已并入大体量主题或舍弃）。
2. **辨识度梯度**：每个主题混入高/中/低辨识度点，配合 easy/hard 模式。
3. **空间分散**：避免点位过度集中在一省，保证全国模式可玩。
4. **可批量获取**：优先选有官方名录或权威列表的主题，能一次性拿到 50~500 个点。
5. **合规**：仅用公开名录 + 名称，坐标用地图 API geocode；不抓取受版权保护的图鉴/点评数据。

### 已舍弃/合并的小体量主题（<50，不单独立题）
- 峡谷、瀑布、火山、温泉、冰川、沙漠 → 并入 `geo_park`（国家地质公园）
- 超长隧道、电视塔、航天发射场、核电站 → 体量不足 50，舍弃（核电站/发射场可精选 10~20 个作为"彩蛋题"穿插，不单独成主题）
- 985 院校（39 所）→ 并入 `university_211` 作为高辨识度子集
- 各省最高/最低点（各 34）→ 合并为 `prov_extreme`（各省地理极值）

## 4. 难度与模式适配

| 模式 | 建议主题 | 理由 |
|---|---|---|
| easy（可缩放/点击判定） | 211/双一流、世界遗产、5A、摩天大楼、机场、主题乐园、度假区 | 辨识度高，全国分布均匀，新手能猜 |
| hard（缩放锁定） | 知名山峰(5000m+)、各省极值、地质公园、考古遗址、水坝、名镇名村 | 辨识度低，靠地形/经纬度推理，硬核玩家向 |
| PK 对战 | 名山、湖泊、河流节点、历史文化名城、大桥、港口 | 中等难度，双方公平，提示系统有用武之地 |

## 5. 数据获取与落库流程

### 5.1 名称清单
1. 优先从政府/权威名录站点爬取或复制名称+所在省（无坐标也可）：
   - 5A / 国家级旅游度假区 / 红色旅游：`https://sjfw.mct.gov.cn/site/dataservice/rural?type=10`
   - 211/双一流：教育部官网历年公告
   - 世界遗产：UNESCO WHS 列表
   - 历史文化名城/名镇名村：住建部、国务院批复公告
   - 国家一级博物馆/国保/考古遗址公园：国家文物局
   - 国家地质/森林/湿地公园：自然资源部、林草局
   - 摩天大楼：CTBUH `skyscrapercenter.com`
2. 存为 `backend/data/themes/<category>.csv`（列：name, province, optional lng/lat）。

### 5.2 坐标补齐（Geocoding）
- **推荐**：高德 Web 服务 API `geocode/geo`（需 key，已在项目配置）。批量按名称+省份查询，返回 GCJ-02 坐标。
- **转换**：GCJ-02 → WGS84 用 `coordtransform` 算法（后端 Python 库 `coord-convert`），入库统一 WGS84，与 Leaflet/卫星瓦片对齐。
- **兜底**：维基百科条目页右上角坐标（WGS84）直接用；OSM Nominatim（限频 1 req/s）。
- 单主题批量脚本示例：`backend/scripts/geocode_theme.py`，读 CSV → 调高德 → 转换 → 写回 CSV 新列 `lng_wgs84, lat_wgs84`。

### 5.3 入库
- 扩展 `seed_data.py`：新增 `import_theme_pois(category, csv_path)`，读 CSV 批量 `INSERT INTO pois`，`cover_url` 留空（后续按需补 OSS）。
- `hint_text` 可用模板生成（如 211 院校："位于{省份}的 211 院校，{建校年份}年建校"），或人工编写精炼线索。
- `difficulty` 按主题默认值 + 个别微调。

### 5.4 前端选场
- Home 页主题选择器：按 `category` 分组展示，显示每主题点数与平均难度。
- 后端 `start_game` 增加 `category` 参数，选题时 `WHERE category = ? ORDER BY RANDOM() LIMIT 1`。

## 6. 优先级建议

| 批次 | 主题 | 理由 |
|---|---|---|
| P0（先做） | 211/双一流、世界遗产、5A、名山、湖泊、机场、历史文化名城 | 名单权威、辨识度高、覆盖全国，快速见效 |
| P1 | 摩天大楼、大桥、港口、高铁站、一级博物馆、名镇名村、主题乐园 | 数据易得、传播点强 |
| P2 | 各省极值、地质/森林/湿地公园、考古遗址、水坝、工业旅游 | 硬核向，体量大但制作成本高（需逐点核坐标） |

## 7. 风险与合规

- **坐标偏差**：高德/百度返回 GCJ-02，必须转 WGS84 再入库，否则与 ArcGIS/天地图卫星瓦片错位（已有 AMAP 瓦片是 GCJ-02，但 POI 判定用经纬度距离，统一 WGS84 更稳）。
- **数据时效**：5A/双一流/历史文化名城会增补，每年同步一次官方名单。
- **版权**：仅用公开名录的"名称+所在省"，不复制景区图文/点评；`summary` 用自撰一句话，`cover_url` 用自有 OSS 或 CC0 图片。
- **敏感点**：核电站、军事相关、边境敏感设施不单独成主题；工业旅游仅收录官方公布的示范基地。
- **辨识度下限**：避免收录查无资料的小点（如无坐标、无名气的村），保证结算页能给出有意义的 `summary`。
- **体量门槛**：任何主题入库前先核验有效 POI ≥50，不足则合并或缓发。

## 8. 验收标准

1. 至少落地 10 个主题（P0 全量），**每主题有效 POI ≥50**（有名称、坐标、adcode、hint）。
2. 坐标与卫星瓦片偏差 ≤50m（肉眼对得上地标）。
3. 前端可按主题选场，每局目标点落在所选主题池内。
4. 每个主题的 `hint_text` 不直接含地名，且能引导推理。
5. 单主题池内点位省域分布 ≥10 个省，避免过度集中。
