# 困难模式操作栏体验优化方案

> 状态：方案文档（不改代码）
> 范围：困难模式（缩放锁定）下的地图移动操作体验（仅桌面端），单人 / PK 通用
> 现状参考：`frontend/src/pages/Game.tsx`、`frontend/src/pages/PKGame.tsx` 左侧操作面板

---

## 1. 现状描述

困难模式下缩放被锁定，"平移"是唯一的探索手段。当前输入方式有两套并行：

| 输入方式 | 实现 | 特点 |
|---|---|---|
| 拖拽地图 | Leaflet 默认 drag（含惯性） | 连续、直观，但没有距离感，长距离移动要反复拖拽 |
| 8 方向按钮 + 距离档 | 西北/北/东北/西/东/西南/南/东南 + 10/50/100/500km + 自定义 km 输入框 | 精确、可量化，但离散：长距离要连点很多次 |

面板还混入了"提示系统"（省份/坐标/区域），整块面板常驻左侧、不可收起。

## 2. 问题清单

1. **离散按钮 vs 连续拖拽割裂**：8 方向按钮一次只走一个固定档位，跨省移动要点几十次；自定义 km 要唤起键盘输数字，打断操作流。拖拽则完全没距离反馈，"我到底移了多远"不可知。
2. **距离档位与模式不匹配**：10/50/100/500km 是全国尺度。省级模式视野只有几十到几百公里，最小档 10km 一步就飞出目标区；全国模式 10km 又几乎看不见位移。档位没有随模式缩放。
3. **面板常驻、过长、不可收起**：方向键 + 档位 + 输入框 + 提示系统堆在一起，桌面端占左侧约 240px，遮挡地图且增加认知负担。提示系统与移动控制语义不同，却被塞进同一块面板。
4. **移动反馈缺失**：点方向键后地图瞬移（或短动画），没有轨迹线、没有"本次位移 xx km"的反馈；玩家难以建立空间记忆。
5. **桌面键盘零支持**：同类游戏（GeoGuessr）玩家肌肉记忆是 WASD/方向键，我们完全没接键盘。

## 3. 行业参考

### 3.1 GeoGuessr 的操作模型
- 鼠标拖拽平移、滚轮缩放；键盘 **W/S 前后移动、A/D 左右平移、方向键平移**；Space 提交。
- **长按 Space/Enter 悬停在方向箭头上 = 连续快速移动**（免重复点击）。
- **C 检查点**（保存/返回位置）、**R 回到起点**、**Z 撤销上一步移动**——导航容错三件套。
- 小地图 hover 展开、图钉锁定、可调整大小——辅助信息"按需出现"，不常驻。

### 3.2 Leaflet 能力盘点（现成可用）
- `inertia` 默认开启（`inertiaDeceleration: 3400 px/s²`、`easeLinearity: 0.2`），拖拽手感本身合格。
- `map.panBy(offset, {animate})` / `panTo(latlng)` 可做平滑位移动画。
- 内置 `keyboard` handler（方向键平移、+/- 缩放），但我们建图时 `keyboard: false` 关掉了；且内置 panDelta 固定，方向只有 4 向，**建议自绘 keydown 接管**。
- `L.control.scale` 比例尺控件可一行加上，直接补足"距离感"。

## 4. 优化方案（按优先级）

### 4.0 总体思路

用「屏幕边缘 8 方向按钮 + 点击次数加速巡航」取代现有常驻操作面板。点击一次启动该方向持续平移，连续点击指数加速，配合实时速度显示与距离跳转输入，把"平移"从离散点按变成有节奏、有旅程感的连续移动。键盘与按钮共用同一套加速曲线。

### P0 — 低成本高回报，建议先做

#### 4.1 边缘 8 方向按钮 + 点击加速巡航
- 屏幕四边中点放 4 个正向按钮（北/南/西/东），四角放 4 个斜向按钮（西北/东北/西南/东南），共 8 个，贴边悬浮在地图之上。
- **巡航机制**：点击某方向按钮 → 该方向开始持续平移（`panBy` 循环）；再次点击同方向 → 提速一档；点击反方向、点击中心停止键、或按 Space → 停止。
- **加速曲线（指数，以 km/秒为单位）**：

  | 点击次数 | 速度 |
  |---|---|
  | 第 1 次 | 10 km/秒 |
  | 第 2 次 | 20 km/秒 |
  | 第 3 次 | 40 km/秒 |
  | 第 4 次 | 80 km/秒 |
  | 第 5 次 | 160 km/秒（封顶） |

- 单位说明：直接以 km/秒计量速度（1 屏 ≈ 10 km，困难模式缩放锁定、视野固定，km 与像素换算稳定）。封顶 160 km/秒，北京到喀什约 4000 km 仍需约 25 秒，长距离探索体感合理。
- 按钮常态半透明（0.3~0.4），hover / 激活时高亮不透明；激活方向按钮常驻高亮直到停止。
- 斜向按钮触区要够大（建议 ≥48px），四角易误触，需与地图 drag 热区留 ≥8px 间距。
- 风险与对策：指数加速 4 次点击即 80 km/秒，可能越过大目标；建议封顶 160 km/秒，并保留 Shift 精细模式（速度/5）与撤销兜底。

#### 4.2 键盘操作（与按钮同曲线）
| 按键 | 行为 |
|---|---|
| W / ↑ | 向北巡航 |
| S / ↓ | 向南巡航 |
| A / ← | 向西巡航 |
| D / → | 向东巡航 |
| Q / E / Z / C | 斜向巡航 |
| Space | 停止当前移动 |
| Shift（组合） | 精细移动：速度降为 1/5 |
| 1 / 2 / 3 / 4 | 切换距离跳转档 |

实现要点：`window` 上 keydown/keyup 自绘，输入框聚焦时忽略（`e.target instanceof HTMLInputElement` 直接 return）；按住方向键复用 4.1 加速曲线（每 250ms 升一档）。

#### 4.3 速度显示 + 距离跳转输入
- 屏幕一角（建议右下）常驻速度计：显示当前移动方向 + 速度（如「→ 40 km/秒」），静止时显示「—」。
- 旁边放距离输入框：输入数值 + 单位 km，回车后地图中心沿当前激活方向平滑跳转该距离（无激活方向时沿用上次方向或提示选择）。
- 速度计下方显示累计移动距离（后端已有 `total_distance_km`，前端展示即可）。
- 配合 `L.control.scale` 比例尺，让玩家直观感知"每秒跨越多少 km"。

#### 4.4 移除操作面板 + 提示系统分离
- 删除左侧常驻操作面板（方向键 + 档位 + 输入框整块）。
- 提示系统（省份/坐标/区域）拆为顶部/右侧独立 💡 按钮 + 弹层，按需出现。
- 地图获得全屏可用面积，旅程感更强。

#### 4.5 距离档随模式自适应（用于跳转输入）
固定 10/50/100/500 改为按模式给默认档位（单位 km）：

| 模式 | 档位建议 |
|---|---|
| national | 10 / 50 / 100 / 500 |
| provincial | 1 / 5 / 20 / 50 |

档位作用于 4.3 的距离跳转输入（± 步进 = 当前档最小值），巡航移动不受档位影响。

#### 4.6 移动反馈
- 启动/停止巡航时 toast 提示「向北巡航 40 km/秒」/「已停止」。
- 巡航过程中持续绘制运动方向尾迹（一条沿移动方向的渐变线，跟随中心移动），1.5s 淡出，强化"在旅途"的感觉。
- 速度计实时跳动，配合比例尺让玩家感知"每秒跨越多少 km"。

### P1 — 体验升级

#### 4.7 点哪去哪（click-to-pan，桌面）
- 点击视野内任意点，地图中心平滑移到该点（`panTo`，duration 按距离 0.3~0.8s）。
- 与拖拽不冲突：Leaflet 的 `click` 在拖拽后默认不触发，天然区分 click/drag。
- 建议作为**可选开关**（设置里"点击移动"默认开），与边缘按钮并存：长距离用巡航，微调用点击。

#### 4.8 导航容错三件套（学 GeoGuessr）
- **撤销（Z / 按钮 ↩）**：维护移动历史栈，一键回退上一步（走后端 move 反方向，保证服务端同步）。
- **回到本轮起点（R / 按钮 ⌂）**：记录开局中心，反方向 move 回去。
- 价值：敢大胆高速移动，不怕"走丢"。

### P2 — 可选增强
- 设置记忆：上次距离档、速度封顶偏好存 localStorage。
- 斜向按钮的加速曲线与正向一致。
- 速度计换成指针/仪表盘样式，增强旅程仪式感。

## 5. 关键交互参数建议

| 参数 | 建议值 | 说明 |
|---|---|---|
| 巡航启动 | 单次点击 / 单次按键 | 立即开始持续平移 |
| 加速间隔 | 250ms（键盘长按）/ 即时（按钮连点） | 每次升一档 |
| 加速曲线 | 10→20→40→80→160 km/秒（×2） | 160 km/秒封顶 |
| 精细移动 | Shift 按住 = 速度/5 | 末段逼近目标 |
| 停止方式 | Space / 中心停止键 / 反方向 | 任一即可 |
| 边缘按钮触区 | ≥48px | 斜向尤需加大 |
| 按钮常态透明度 | 0.3~0.4 | 不扰地图 |
| panBy 单步时长 | 0.25s | 巡航循环步长 |
| 轨迹线淡出 | 1.5s | 反馈但不残留 |
| 距离跳转动画 | 0.3~0.8s | 按距离自适应 |

## 6. 验收标准

1. 桌面：全程不碰鼠标，仅键盘可完成一局困难模式（巡航、加速、停止、跳转、撤销）。
2. 跨省 300km 级移动：从 ≥3 次点击降为 2~3 次连点（≤1s 内提速到 80 km/秒）。
3. 省级模式最小步长 ≤1km（通过 Shift 精细或距离跳转实现），不再"一步飞出目标区"。
4. 每次移动有可见反馈（轨迹线/速度计/toast），玩家能说出"当前速度与已移动距离"。
5. 操作面板移除后，地图可视面积增加，左侧不再有常驻遮挡。

## 7. 风险与注意

- **指数加速过冲**：4 次点击即 80 km/秒，需封顶 160 km/秒 + Shift 精细模式 + 撤销兜底。
- **巡航停止机制**：必须有显式停止键（Space / 中心停止键 / 反方向），避免玩家"停不下来"。
- **km/秒与像素换算**：`panBy` 按像素移动，需按当前缩放级别把 km/秒换算为像素/秒；困难模式缩放锁定，换算在单模式内稳定。
- **边缘按钮误触**：与地图 drag、click-to-pan 热区冲突，需明确按钮优先级与 ≥8px 间距；按钮半透明避免遮挡。
- **click-to-pan 误触**：必须依赖 Leaflet 的 drag 抑制 click 行为，且不要自定义 click 阈值；与简单模式"点击落点"严格隔离（仅困难模式启用），按钮区域不触发 panTo。
- **键盘与输入框冲突**：距离输入框聚焦时全局 keydown 必须放行。
- **撤销的服务端一致性**：判定以服务端 view 中心为准，撤销必须走后端 move（反方向），不能只改前端地图位置。
- **PK 公平性**：所有操作优化对双方同时生效，不涉及判定规则变化，无平衡风险。

## 8. 落地顺序建议

1. 第一批（P0 全量）：边缘 8 方向按钮 + 点击加速巡航 + 键盘 + 速度计/距离输入 + 移除面板/提示分离 + 档位自适应 + 移动反馈。改动集中在前端两个页面，后端零改动。
2. 第二批（P1）：click-to-pan 开关 + 撤销/回起点。
3. 第三批（P2）：按数据/反馈决定是否做。
