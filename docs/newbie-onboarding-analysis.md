# 新手门槛分析与新手模式建议

> 状态：思考文档（不改代码）
> 由来：朋友玩后反馈「这个游戏对我来说太难了。提示搞一个黄色矩形，但范围还是非常大。然后提的什么乔家大院、什么卢宅这些地方，我他妈听都没听过，根本无从下手。」作者回应：niche 路线不降难度，但承认门槛要修（POI 过一遍补省市、小众分层、菜鸟有效反馈），且「先让自己上头」是第一标准。
> 关联：`hard-mode-difficulty-reflection.md`（难度矩阵与坡道）、`hard-mode-control-ux.md`（交互卫生）。本文不重复其结论，聚焦「第一局的门槛」与「新手模式怎么落地」，并在第 7 节给出作者完整立场与综合判断。

---

## 1. 朋友观点拆解

朋友的话里其实有两层，要分开：

| 层次 | 内容 | 是否成立 |
|---|---|---|
| A. 需要低门槛入口 | 新手要能玩起来、找到乐趣，否则前几分钟流失 | 成立，且是品类生死线 |
| B. 否则会被老产品抢走 | 接触过 GeoGuessr 的玩家有替代品，不会留 | 部分成立，但抢走他们的不是「门槛高」，是「没有差异化」 |

**关键纠正**：A 和 B 指向相反的方向。
- A 说「要像老产品一样易上手」——往通用靠。
- B 说「接触过老产品的人会回老产品」——恰恰因为你在往通用靠，他才回老产品；通用拼不过成熟产品的打磨度。

所以朋友的前半句（要低门槛）对，后半句（否则抢不到人）的解法不是"更通用"，而是"用低门槛把人引进来，再用差异化留住他"。门槛是漏斗口，差异化是留存闸，两者不能混为一谈。

## 2. 品类定位：与 GeoGuessr/图寻不是同一类游戏

先澄清一个容易混的参照系：GeoGuessr（国内类似"图寻"）是**看图猜地点**——给街景/照片，玩家猜自己在哪并点地图提交，核心是"识别挑战"。我们的产品是**给地名/提示，在锁缩放的地图上挪过去找**，核心是"导航 + 反推挑战"。两者都是地理游戏，但机制不同：

- 识别挑战（GeoGuessr/图寻）：线索 = 视觉（街景、地形、植被、路牌）；门槛 = 视觉记忆 + 常识。
- 导航反推挑战（我们）：线索 = 文字地名 + 区域框；门槛 = 地理知识 + 空间挪移。

这个区分很重要，因为：

1. **"接触过老产品的人会回老产品"这个担心被削弱了**——我们做的不是同一类游戏，没有直接替代品。GeoGuessr/图寻玩家想玩"看图猜地"不会来我们这；我们吸引的是"想挪地图、想靠地名反推"的另一群人。朋友的担心（B 层，见第 1 节）在这里反而消解：差异化本身就把我们和替代品隔开了。
2. **低门槛手法不能照搬**：GeoGuessr 的低门槛靠"街景信息充足 + 自由缩放"，我们机制不同没法抄。能借鉴的只有通则：单局短、第一局即乐趣、失败成本低、不强制爬难度。
3. **差异化即护城河**：正因为和图寻/GeoGuessr 不是一类，我们不需要在"看图猜地"上比打磨度，而要把"挪移 + 反推"这个独特机制做深、做顺、做出旅程感——这是 `hard-mode-difficulty-reflection.md` 一贯的方向。

所以本文后续的"新手模式"建议，是给"导航反推"这类机制做 onboarding，不是模仿 GeoGuessr。朋友的"太难"要靠修自己机制的门槛（目标池 + 提示精度 + 首局引导），而不是变成图寻。

## 3. 当前产品门槛诊断

朋友的反馈戳中的不是操作门槛，是**内容门槛**：目标 POI 太冷门（乔家大院、卢宅）+ 提示精度不足（黄色矩形范围过大）。新手不是"不会操作"，是"无从下手"——没有先验知识，提示又帮不上，等于无解。逐环节诊断：

| 环节 | 现状 | 新手会卡在哪 |
|---|---|---|
| 进游戏 | Home 选模式/难度/省份 | 选择过多，不知道选什么；默认进哪个？ |
| 第一局 | 直接开始，靠顶部目标文字 + 引导电 | 引导电可关，关了之后新手不知道"该往哪看、怎么找" |
| **目标 POI 池** | 主题/省份下随机抽，含冷门小众 POI | **朋友踩中的坑**：抽到乔家大院、卢宅这种听都没听过的地方，先验知识为零，无从下手 |
| **提示精度** | 区域框（黄色矩形）+ 省份/坐标/区域三档 | **朋友踩中的坑**：矩形范围太大，等于没提示；对冷门 POI，即使给省份也推不出在哪 |
| 找目标 | 简单模式有区域框；困难模式纯挪移 | 困难模式新手第一局大概率迷路——这是签名挑战，不是门槛，不该让新手第一局就碰 |
| 反馈 | 命中/未命中 + 距离提示 | 未命中提示已有，但缺"下一步该干什么"的引导 |
| 结算 | 展示目标位置 | OK，但缺轨迹回放（`hard-mode-difficulty-reflection.md` 第 7 节） |

**核心问题**：不是"没有简单模式"，而是**新手第一局默认进哪个、目标 POI 从哪个池里抽、提示精度够不够让他下手**——这三件事没设计。朋友的"无从下手"正是三件事同时失效的叠加。

## 4. 新手模式建议

### 4.1 第一局强制走简单模式 + 高知名度目标池
- 新用户首次进入**默认简单模式**，且第一局目标锁定为强线索 POI（省会、5A 景区、名山），不让新手选省份/主题——选了也是盲选。
- **建立"新手目标池"**：只收大众熟知度高的 POI（北京、上海、西安、拉萨、黄山、故宫、西湖…），**排除乔家大院、卢宅这类冷门**。冷门 POI 留给进阶/主题挑战。这是朋友"无从下手"的直接解药——他听过的目标，才有可能找到。
- 首局加不可关闭的轻量教学条（不是弹窗）：「点击地图放置标记 → 确认 → 距离提示会告诉你多远」，三步走完即消失。
- 目标：首局 2 分钟内命中或接近命中，产生 aha。朋友之所以"无从下手"，根因是目标他听都没听过——换池子比调难度更治本。

### 4.2 难度解锁而非并列展示
- Home 首屏只露「简单」；困难模式在简单模式赢 1 局后解锁（或显式"想挑战自己？"入口）。
- 理由：并列展示时新手会好奇点困难，然后第一局挫败流失。解锁是温柔的默认值设计，不剥夺选择。
- 这不改变难度矩阵（`hard-mode-difficulty-reflection.md` 6.1），只改首屏默认与解锁顺序。

### 4.3 失败不甩出，给"再试一次"的台阶
- 未命中时除距离提示外，补一句可操作的下一步（「目标在你东北方向，试试往那边移」），把"未中"变成"缩小范围"。
- 结算页失败态加「再来一局（换个简单点的地方）」按钮，默认推简单目标，不让新手卡在同一个过难目标上反复受挫。

### 4.4 旅程感前置（不是困难模式专属）
- 简单模式也画本局移动轨迹 + 总里程，结算页展示——让新手第一局就感受到"我跨越了多远"，这是品牌情绪的种子，不该锁在困难模式里。
- 这条与 `hard-mode-difficulty-reflection.md` 第 7 节的轨迹回放一致，只是强调"简单模式也要有"。

### 4.5 提示分级：让"无从下手"变"有迹可循"
朋友说"黄色矩形范围非常大"——当前区域框对新手等于没提示。提示要按难度/局次分级，不是一刀切：

- **新手档提示**：区域框 + 省份名 + 距离方向（「目标在福建省，距你东南约 200km」）。方向 + 省份给新手一个可执行的下一步，而不是一个大框让他瞎点。
- **标准档提示**：区域框 + 省份名（现状三档里的"省份"），去掉方向。
- **硬核档**：仅区域框或无提示（现状困难模式）。
- 原则：提示是"缩小搜索空间的工具"，不是"给答案"。朋友要的不是答案，是**一个能下手的方向**——当前矩形给的是空间范围，但没给"往哪找"的动作指引。加方向 + 省份名，把"范围"变成"路径"。
- 这与 `hard-mode-difficulty-reflection.md` 6.2 的可选救济同向：提示可作为货币汇出口（看广告得一次方向提示），但新手首局免费给，保证不卡死。

## 5. 与现有难度体系的关系

- **不新增难度档**：新手模式不是第四档，是"简单模式 + 首局引导 + 解锁顺序"的组合，是 onboarding 设计不是难度设计。
- **不动签名困难**：困难模式一字不改，它仍是品牌签名。新手模式解决"怎么把人送到能欣赏签名困难的位置"。
- **识图挑战仍作为中间坡道**（见 `hard-mode-difficulty-reflection.md` 6.3），与本文不冲突——识图挑战是难度坡，新手模式是入口流程。

## 6. 落地优先级

1. **P0**：建立新手目标池（高知名度 POI，排除冷门）+ 首局默认简单 + 强线索目标 + 轻量教学条。**这是朋友"无从下手"的直接解药**，改动在后端目标筛选 + Home 默认值，收益最大。
2. **P0**：新手档提示（区域框 + 省份名 + 距离方向），让"大矩形"变"可执行方向"。
3. **P0**：简单模式结算加轨迹回放 + 总里程。与 `hard-mode-difficulty-reflection.md` 第 7 节合并实现。
4. **P1**：难度解锁顺序（简单赢 1 局解锁困难）。
5. **P1**：未命中可操作下一步提示。
6. **P2**：埋点验证（首局完成率、首局后留存、简单→困难跃迁率、新手池目标命中率 vs 冷门目标命中率）。

## 7. 作者立场与综合判断

### 7.1 作者完整立场

作者在与朋友的对话中给出了清晰的、与朋友方向相反但自洽的立场（原话节录）：

- **niche 定位坚定**：目标群体是地理爱好者或地理教学，不是大众休闲游戏。「大众休闲游戏受众那么广，我没有任何机会。」「只有少部分人玩，而且觉得好玩，我才有机会。如果大多数人都觉得好玩，你放心，我没有任何机会。」
- **难的哲学**：「只有难才有趣味，太简单的我没有机会。」「我的目的是让少数人觉得上头，而不是让所有人觉得还行——因为所有人觉得还行，他是不可能付费的，也不可能看广告的，我是不可能变现的。」
- **第一验收标准是"自己上头"**：「第一个先让我自己上头。现在这个模式，我在高德地图上自己划拉能上头，但是我做的还没让我上头，我还要改。」改版后：「我现在玩困难模式还是挺上头的，刚刚改版支持键盘和组合键了，我能玩两个小时。」
- **简单模式现状自评**：「简单模式要么我没听过；听过的基本上 10 秒以内。」——亲测验证了第 3 节的诊断：问题在目标池冷门，不在难度档。
- **承认要改的点**：
  - 「那些地名那些地方，我后面要给他过一遍，要告诉他是哪个省哪个市的某个景点，要不然很懵逼。」= 第 4.5 节新手档提示。
  - 「要把一些非常小众的景点给他提出来。」= 第 4.1 节新手目标池分层。
  - 「如果水平特别菜，怎么在这里面能得到一个有效的反馈……现在唯一的反馈就告诉你距离多少。」= 失败可读性问题。
- **心态**：「我纯粹当爱好做着玩，实在不行我自己一个人玩，无所吊谓。」「我自己这些东西全闹着玩的，变现极难。」——这个心态保护了产品调性：不为变现稀释签名。
- **听意见但不一定采纳**：「我先按照我自己的想法做，我也听所有人的意见和建议，但是我不一定采纳。」

### 7.2 综合判断：两人其实没冲突

把双方话对齐看，分歧只在框架，不在内容：

| 朋友说的 | 作者回应 | 实质 |
|---|---|---|
| 太难、无从下手 | 认同：POI 要过一遍补省市、小众要分层 | 都认：内容门槛是问题 |
| 要有低门槛入口 | 认同：简单模式还不够简单 | 都认：onboarding 要改 |
| 会被老产品抢走 | 反驳：和图寻不是同类，没替代品 | 作者对：差异化即护城河（见第 2 节） |
| （没意识到） | 作者补：图寻也难，但无论多菜都有距离反馈 | 关键不是无门槛，是"失败有有效反馈" |

**作者已经在按朋友的反馈改了**（飞行模式、要过 POI、要补省市、要给菜鸟反馈），只是框架上坚持"我不降难度"——这其实是对的，因为修门槛 ≠ 降山顶。嘴上说不采纳，手上做的大半就是朋友要的。

### 7.3 作者立场里最稳的三点

1. **niche + 变现逻辑自洽**：少数人上头才付费/看广告，所有人"还行"不付费。判断成立，与 `hard-mode-difficulty-reflection.md` 一致。
2. **"先让自己上头"作为第一验收标准**：作者是重度玩家，自己上头是 niche 产品成立的前提。困难模式改版后能玩两小时——飞行模式+键盘组合键的交互方向对了，签名挑战的乐趣被释放。
3. **"听过的 10 秒内、没听过的卡住"**：作者亲测验证内容门槛诊断——问题在目标池冷门，不在难度档。比任何分析都有说服力。

### 7.4 需要警惕的一点

**"先让自己上头"是必要不充分。** 作者永远不会再以新手状态玩第一次。自己上头保证 niche 价值成立，但不保证新人能爬到"上头"的位置。100 个真爱是从池子里筛出来的——作者也承认变现极难、靠其他项目撑着，那流量更金贵，每个进来的新人转化效率不能放任。

但"实在不行自己玩无所吊谓"这个心态反而保护了产品调性——不为变现稀释签名，是健康的。只要不指望它养家，坚持 niche 是对的。这个心态让作者敢做"奇怪"的机制，恰恰是差异化来源。

### 7.5 被作者自己点出、却未充分意识到的洞察

作者说「图寻无论多菜总归能得到一个反馈，比如距离 5000 公里」——这是作者自己点出的关键，比意识到的更重要。当前失败只给距离，但作者想要的是"菜鸟也有有效反馈"。这等于说：**难的合法性 = 失败的可读性**。失败越可读，难越能被接受。这正是 `hard-mode-difficulty-reflection.md` 6.4 的验收原则。作者已在朝这想，只是没把它和"门槛"挂钩——其实它就是门槛：不是降低度，是让挫败可解释。把它从"思考的问题"提升为"签名挑战的配套机制"，是接下来最值得做的一件事。

## 8. 结论

朋友的"无从下手"是两件事叠加：**目标他听都没听过**（内容门槛）+ **提示帮不上忙**（提示门槛）。作者立场正确（niche 不降难度、先让自己上头、差异化即护城河），且已在按朋友的具体反馈改（POI 过一遍补省市、小众分层、菜鸟反馈、飞行模式交互）。两人没冲突——作者嘴上不采纳，手上做的就是朋友要的门槛修复。

解法不是把产品做通用，而是：换池子（新手只抽高知名度 POI）+ 加提示（区域框升级为方向+省份）+ 设计首局（默认简单、教学条、轨迹回放）+ 失败可读（菜鸟有效反馈，难的合法性来自挫败可解释）。门槛是漏斗口，差异化是留存闸——修门槛不等于降山顶，签名困难一字不改。

当前最该做的不是加难度档，而是把"新手第一局"当作一个独立产品来设计：换池子比调难度更治本，给方向比给范围更管用，失败可读比降低度更治挫败。同时持续打磨签名体验（飞行模式已见效，作者能玩两小时），保住山顶。
