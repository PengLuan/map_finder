## 一、功能定位

将"8 月热点事件专题"升级为独立常驻功能 **「小寻带你看新闻」**（备选名「小寻带你吃大瓜」，待确认）：

- 以**新闻事件**为单位组织内容，不再挂靠现有 easy/hard 难度专题体系
- 玩法：沿着**时间线**在地图上依次寻找事件发生地；找齐后解锁该事件的**新闻简介**，并可跳转**第三方新闻报道链接**阅读原文
- 与游戏内普通专题（勋章体系）剥离开，作为独立栏目/独立入口

## 二、核心玩法（草案）

1. **时间线叙事**：每个新闻专题是一条时间线，点位按事件发生时间排序（如 8 月台风线：白海豚登陆 8/9 → 沙德尔二次登陆 → 三登坎门 8/28）
2. **顺线找点**：玩家从时间线第一个事件开始，在地图上定位该事件地点；命中后自动推进到下一事件
3. **解锁新闻卡片**：每找到一个点，展示该事件的新闻简介（一句话 + 地理冷知识）；全部找齐后解锁完整时间线回顾 + 每个事件的第三方报道链接
4. **新闻卡片**：标题、日期、简介、地点、"阅读原报道"外链按钮

## 四、可拓展方向（后续迭代候选）

- 新闻线索 UGC：用户投稿新闻事件点（复用投稿/纠正的审核流）
- 每周/每日热点速更：小事件做成 1-3 点的微型时间线
- 事件回顾档：老时间线归档可玩，不删除
- 分享：时间线完成海报（事件 + 日期 + 用时）
- 与勋章体系挂钩：完成时间线发纪念徽章（是否与其他专题一致，待确认）

## 五、待确认项

| # | 事项 | 说明 |
|---|------|------|
| N1 | **功能命名** | 「小寻带你看新闻」vs「小带你吃大瓜」vs 其他；影响入口文案与调性 |
| N2 | **内容调性边界** | "看新闻"偏严肃时事，"吃大瓜"偏娱乐八卦；两者口径、审核标准不同，需定调（灾害类事件无论哪种调性都按"救援+科普"克制处理） |

| N4 | **链接失效策略** | 新闻页可能被删除/付费墙：定期巡检、失效后仅保留简介、或存快照摘要 |
| N5 | **完成奖励** | 发纪念徽章（与其他专题一致）？积分？还是纯打卡无奖励 |
| N6 | **入口位置** | 首页独立入口（图标/卡片）、专题列表内独立 tab、还是两者都有 |

| N8 | **时间线组织粒度** | 按月出一期大合集，还是按事件/主题出多条独立时间线（当前素材是按主题 4 条） |
